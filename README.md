# 💰 Calculadora de Honorários

> Sistema desenvolvido em Java para auxiliar escritórios de contabilidade na precificação de honorários.

## Sobre o projeto

A definição de honorários contábeis ainda é, em muitos casos, baseada exclusivamente na experiência do contador. Isso faz com que a precificação seja subjetiva e, em algumas situações, não reflita corretamente os custos do escritório ou a margem de lucro desejada.

Este projeto nasceu com o objetivo de tornar esse processo mais simples, padronizado e objetivo.

A Calculadora de Honorários é uma aplicação desktop desenvolvida em **Java** utilizando **Swing (JFrame)**, que permite calcular o valor sugerido para os serviços contábeis com base nas características de cada cliente.

## Como funciona

O usuário informa dados como:

- Regime tributário da empresa;
- Número de funcionários;
- Existência de pró-labore;
- Serviços contratados (Departamento Pessoal, Fiscal, Contábil, entre outros).

A partir dessas informações, o sistema realiza o cálculo considerando a margem de lucro definida pelo usuário e apresenta um valor sugerido para os honorários.

Caso seja necessário, o valor pode ser ajustado manualmente antes da proposta ser apresentada ao cliente.

## Tecnologias utilizadas

- Java
- Swing (JFrame)
- Programação Orientada a Objetos (POO)

## Objetivo

Mais do que desenvolver uma aplicação em Java, este projeto busca resolver um problema real enfrentado por escritórios de contabilidade, utilizando a tecnologia para tornar a precificação mais consistente, prática e transparente.
